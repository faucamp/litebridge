### Litebridge 0.3.1 Release Notes

Litebridge 0.3.1 is mostly a cosmetic release to align with future versions.
It has the same functionality as [version 0.3.0](release-notes-0.3.0.md), but reverts the main
package to `org.litebridge`.

Future versions will keep using the `org.litebridge` package.

### Added
- None.

### Changed
- Renamed main `org.litebridgedb` package back to original `org.litebridge`
- JavaDocs expanded

### Deprecated
- None.

### Removed
- None.
