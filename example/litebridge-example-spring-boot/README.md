# Spring Boot starter example

## Overview

This example uses `litebridge-spring-boot-starter` to set up Litebridge via Spring Boot configuration.

It uses Litebridge Spring repositories, and annotated Litebridge entities.

## Running the example

1. Start the Spring Boot app by running the `AutoConfigurationApplication` main class.
2. Access the Swagger page at `http://localhost:8080/swagger-ui/index.html`.
3. Use the Swagger UI to test the Litebridge Spring repositories.
